# 第8回：カスタマージャーニー

- あらゆる人工物 → デザインの対象
	1. 製品
	2. 商品、サービス、コミュニティー
	3. インターフェース
	4. マルチユーザーシステム / ネットワーク
		- YouTubeに動画をアップロードするなど、参加型の話。
	5. プロジェクト
	6. ディスコース
- As is / to Be
	- How Might We~?
		- （どうしたら〜できるだろうか？）
	- 問いのフォーカスを調整する
		- 抽象的
			- （コンビニに通うことで）健康になるにはどうすればいいか？
			- 「薬局があればいいの？」など、考えがぶれてしまう。
		- 具体的
			- 毎日野菜を摂るにはどうすれば良いか？
	- ペルソナシートが「人生相談レベル」の解像度にならないよう、注意する。
		- 「先輩の仕事の愚痴を聞くのが正直、めんどい。」
			- 長々した飲み会に付き合うのがしんどい。
			- つい話を合わせて盛り上がっちゃって飲みすぎる。
			- でも、全然楽しくない酔い方をするから嫌だ。
