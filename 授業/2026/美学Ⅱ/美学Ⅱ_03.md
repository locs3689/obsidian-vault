# 第3回

- 「霊感」と「天才」は、ヨーロッパで繋がる概念？ #要確認 
- inspiration（動詞: inspire）
	- ラテン語「inspiratio」が起源。
	- ラテン語の「inspire」
		- in（中に） + spire（息をする） ≒ 息を吹き込む
		- 何者かに（超越的な存在に、神に）息を吹き込まれること
	- 非合理的／超合理的／超自然的なものから発想を得ること
	- 得られた発想そのもの
- 本人にもなぜ閃いたかわからないから「ひらめき」。
- enthusiasm
	- inspirationを受けているときの、何かに没頭した心理状態、熱狂
	- ギリシャ語「entheos」 ≒ en（～の状態になる） + theo（神）
	- 神の状態になること ≒ 神がかり
- spireを用いた他の語
	- expire（効力を失う、逝去する）
		- クレジットカードなどでも使う。
	- ex = eks（外） + spire（息をする）
- 接頭辞enを用いた語
	- enrich（richな状態にする）
	- enlarge（largeな状態にする）

- mania
	- 精神の病：病気
		- 日本では「狐がついた」と表現。
		- 「座敷牢」
	- entheos ≒ 神がかり（神的狂気）
		- 人間にとって良いもの、プラスの価値を持つ。
- 神的狂気の例
	- 宗教、芸術創作、その他
	- 預言、秘儀、詩の創作（→芸術の創作全体に拡大解釈）、恋愛
- 古代ギリシャの宗教的中心地「デルフィー」では、予言が行われていた。
