# 第5回

## 「天才」概念の諸要素（つづき）

3. 「天才」vs「能才」
	- ex.1：デュボス
		- 天才は「血」の問題である（血 ≒ 霊感あるいは熱狂の力）
		- 天才には技巧はものの数ではない（身に付けようと思えばすぐに身に着く）。
		- 芸術作品で重要なのは発想であり、それが芸術家とアルティザンとを分ける。
	- ex.2：ヘーゲル
		- 能才：個別的な芸術の技術、身体的に鍛えられた技の持ち主
		- 天才：作品に真の芸術にさせる英気（霊機）を与える
		- 両方があって初めて優れた芸術創作が可能となる。相互補完的な関係。
4. 天才と独創性
	- 天才の作品
		- かつて見たことのない表現や観念、新しい思想がある
	- 発見 ≒ 着想の能力
