# 第5回

## 「天才」概念の諸要素（つづき）

3. ==「天才」vs「能才」==
	- ex.1：デュボス
		- 天才は「血」の問題である（血 ≒ 霊感あるいは熱狂の力）
		- 天才には技巧はものの数ではない（身に付けようと思えばすぐに身に着く）。
		- 芸術作品で重要なのは発想であり、それが芸術家とアルティザンとを分ける。
	- ex.2：ヘーゲル
		- 能才：個別的な芸術の技術、身体的に鍛えられた技の持ち主
		- 天才：作品に真の芸術にさせる英気（霊機）を与える
		- 両方があって初めて優れた芸術創作が可能となる。相互補完的な関係。
4. ==天才と独創性==
	- 天才の作品
		- かつて見たことのない表現や観念、新しい思想がある
	- 発見 ≒ 着想の能力

## 「模倣」の意味と言葉の問題

- ある存在の、あるあり方を模範として、それに倣（なら）うこと、およびその結果として生み出される模像、模範と模像の間との関係
- 模像 → 形のあるもの

- ==mimêsis==（ギリシャ語）
	- ミーメーシスまたはミメーシス
	- 動詞：mimeisthai
	- ラテン語「imitation」 → 各国語 ≒ 模倣
- imitatio（ラテン語）
- imitation（英語）

1. 行為：倣う（真似する）
2. もの：模像
3. 関係

## 類似概念・同義語

- 複製／コピーの意味の同義性と差異
	- 模写 vs 贋作
		- 模写にはオリジナリティがあり得る。
		- 贋作にクリエイティビティが出たら、それは贋作ではない。
	- 模倣 vs 剽窃
		- 模倣は真似した人のパーソナリティが出る。
		- 剽窃はただ盗むだけ。
			- よくあるのは論文。
			- （論文盗作疑惑のケンブリッジ大学元教授が死去）
- 表象（representation）
	- 実質的に同義語
	- 「イメージとして現れる」
	- represent, representer：再現する ≒ 諸芸術全般に共通する性質

- 表演（perform、演劇、舞踊）
- 演奏（音楽）
- 文学（言葉による再現）
- 美術（形や色彩による再現）etc.（→アリストテレス『詩学』）
