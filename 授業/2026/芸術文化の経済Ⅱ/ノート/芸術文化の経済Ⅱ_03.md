# 第3回

## 文化的価値とは？

- 人気・興味に左右されない。
- スロスビーは以下の6つに分類
	- 美学的価値
		- 美しいものに価値がある。
		- 無条件に美しいと思えるものもあれば、流行や権力者の好みに左右されることも。
			- 文化史は権力者の好みの歴史ともいえる。
		- 流行は20-30年で周期する。
			- 若いころに影響を受ける → 決定権を持つ頃に再現。
			- 流行色は2年くらい前に協会が決める。
				- 流行色の素材を用意する時間を確保。
	- 精神的価値
		- 特定の集団や宗教に限定されたものか，人類一般に共通したものかを問わず，理解，啓蒙，洞察等を与えるもの。
			- その存在から学ぶことができるもの。
	- 社会的価値
		- 文化的な財が他者との連帯感をもたらすことによって生まれる。
			- 文化的な財の存在によって他人とのコミュニケーションを図ったり、関係性が広がっていくもの。
	- 歴史的価値
		- 現在と過去の歴史との繫がりを映し出すことで生まれる。
		- 古いこと自体に価値がある。
		- 目に見えてわかる価値。
	- 象徴的価値
		- 作品を解釈することによって引き出される意味の貯蔵庫であることによって認められる
		- 文化的な財からのメッセージ性。
		- どれだけの人に影響を与えたか？ということ。
	- 本物の価値
		- 文化的な財が本物であること自体によって認められる。
			- 偽物ではない。何かオリジナルな部分がある。
		- （例）引用に求められるもの
			1. 引用元を明記
			2. 引用元を何か一つでも超える
				- マネやパクリではない部分が存在
- 文化的価値の測定方法について、スロスビーは以下の5つを提唱。
  お金に関するものは出てこない。
	- 図式化
		- さまざまな位置づけを明確に。
			- 属性の把握。
			- 5W1Hをクリアにして、辞書的な説明をできるようにする。
	- 厚い記述
		- 関連事項の整理
			- 誰から影響を受け、誰に影響を与えたのかを考察。
			- その作品や人物から、いかに広がりを持っていったか？
	- 態度分析
		- その財に触れた人の反応
			- これはアンケート調査などで導く。
			- 文化的価値でいえば、精神・象徴の部分をどれだけ感じたかを考察。
	- 内容分析
		- 内容を深く掘り下げる
			- 厚い記述とは真逆で、構成要素に分解して具体的に優れているポイントをより明確にする。
	- 専門的鑑定
		- 専門家に聞く。合議制が望ましい。
			- 専門家の知識に頼るのは大事なのは前提。
			- 意見の偏りをなくしたりより多くの専門家がお墨付きを与えるという点で合議制が求められる。
			- 実際に世界遺産の審査も合議制の下行われている。

## 他に考えるべき問題

- 一般的な経済学者
	- 経済システムの機能において文化は関連ない。
	- 文化もそのシステムの中に内包されているので個別の問題として考察する必要はない。

![[image-2.webp|253]]

- スロスビーの主張
	1. 個人の意思決定（＝価値観の形成）に、文化・芸術は非常に大きな存在。
		- スルーするのは困難。
	2. 文化的価値が高いモノは高いお金を払っても入手したいと思う傾向がある。
		- 絵画・彫刻品・生原稿などなど。
		- モノ自体の物質的な価値・機能性ではなく、そのモノに存在する文化的な価値を高く評価し、結果として高額の支払い意思につながっていく。
		- 例外1: ハイカルチャー
			- 多くの人が興味を持たないので支払い意思が存在しない。
			- その場合価格が安くなるか、商品自体が存在しなくなるかになってしまう。
		- 例外2: 文化遺産
			- 観光資源となりうる反面、使い勝手の悪さや管理コストの高さや耐久性の問題で取り壊しの例も増えてきている。
			- 奈良女子大学に入ったとき「小さかった」と先生は話す。
			- 原爆ドームも「壊れた状態のまま壊れないように」しなければならない。
		- 例外3: 大衆文化
			- 人気はあるので多くの人が支払い意思を持つが、そこからメッセージ性を受け取ったり、知見を受け取ったりできるとは考えにくい面もある。

## 具体例: 美術館の経済的価値

- フロー（流れる）の価値
	- 私的財
		- 直接美術館が得るお金や満足度で表現される。
			- 入場料収入
			- 入場者の満足度
			- 美術館によるサービスからの便益
	- 公共財
		- 地域内に建物があることによる利益。
			- アイデンティティ
			- 将来世代への継承・調査研究の成果
			- 地域のコミュニケーション
	- 外部性
		- いわゆる経済効果。
			- 交通費
			- 感想戦を行う際の周辺の店への飲食代
			- （遠方の場合は）宿泊費
- 収集、保存、修復、維持
	- 文化的価値の蓄積の機能。
	- 美術館のメインの仕事。
