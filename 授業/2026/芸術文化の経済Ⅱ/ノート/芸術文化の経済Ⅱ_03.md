# 第3回

## 文化的価値とは？

- 人気・興味に左右されない。
- スロスビーは以下の6つに分類
	- 美学的価値
		- 美しいものに価値がある。
		- 無条件に美しいと思えるものもあれば、流行や権力者の好みに左右されることも。
			- 文化史は権力者の好みの歴史ともいえる。
		- 流行は20-30年で周期する。
			- 若いころに影響を受ける → 決定権を持つ頃に再現。
			- 流行色は2年くらい前に協会が決める。
				- 流行色の素材を用意する時間を確保。
	- 精神的価値
		- 特定の集団や宗教に限定されたものか，人類一般に共通したものかを問わず，理解，啓蒙，洞察等を与えるもの。
			- その存在から学ぶことができるもの。
	- 社会的価値
		- 文化的な財が他者との連帯感をもたらすことによって生まれる。
			- 文化的な財の存在によって他人とのコミュニケーションを図ったり、関係性が広がっていくもの。
	- 歴史的価値
		- 現在と過去の歴史との繫がりを映し出すことで生まれる。
		- 古いこと自体に価値がある。
		- 目に見えてわかる価値。
	- 象徴的価値
		- 作品を解釈することによって引き出される意味の貯蔵庫であることによって認められる
		- 文化的な財からのメッセージ性。
		- どれだけの人に影響を与えたか？ということ。
	- 本物の価値
		- 文化的な財が本物であること自体によって認められる。
			- 偽物ではない。何かオリジナルな部分がある。
		- （例）引用に求められるもの
			1. 引用元を明記
			2. 引用元を何か一つでも超える
				- マネやパクリではない部分が存在
- 文化的価値の測定方法について、スロスビーは以下の5つを提唱。
  お金に関するものは出てこない。
	- 図式化
		- 辞書的な説明をする。
	- 厚い記述
	- 態度分析
	- 内容分析
	- 専門的鑑定
